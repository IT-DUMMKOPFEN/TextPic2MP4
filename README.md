# TextPic2MP4

Deutschen Text mit einer Frauenstimme vorlesen lassen und zusammen mit einem Bild als **MP4-Video in 720p** speichern.

| Ordner | Plattform | Stimmen |
|---|---|---|
| [`desktop/`](desktop/) | macOS (Apple Silicon) & Linux – Python/tkinter | Microsoft Neural (edge-tts, online) |
| [`android/`](android/) | Android 10+ – Kotlin, ohne Fremdbibliotheken | Stimmen des Handys (offline) |

## Android-APK

Wird bei jeder Änderung in `android/` automatisch von GitHub Actions gebaut.
Download: **Releases → `Text2Video.apk`** – direkt auf dem Handy öffnen und installieren.

## Desktop

```bash
cd desktop
bash install.sh
./start.sh
```

Details in den READMEs der Unterordner.
